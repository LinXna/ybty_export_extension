# 雷速固定参考材料

此目录只保存可长期复核解析规则的材料，不参与扩展运行。

- `api-docs/leisu-api-response-fields.txt`：雷速 API 返回字段说明，用于字段语义佐证。
- `frontend-sources/`：从完整 HAR 中筛出的前端包；包含详情、近期战绩、联赛积分、进球分布、走势和统计展示逻辑。
- `verified-materials/`：已经与页面或前端规则核对过的解密结果、运行时数据和接口样本。
- `legacy-tools/`：早期接口迁移实验代码；不被 manifest 加载。

新增固定材料时，应在本文件写明来源和作用。普通验证文件继续放在根目录 `导出结果/`，不要混入此目录。
