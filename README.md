# 足球分析数据导出扩展 2.8.0

## YBTY

- `导出滚球分析数据`：导出当前正在进行、且用户已经展开的比赛，文件名为 `ybty_live_*.json`。
- `导出赛前分析数据`：导出尚未开始、且用户已经展开的比赛，文件名为 `ybty_prematch_*.json`。
- 不导出页面不存在的红牌数量。
- `-` 或临时缺少赔率不再自动等同于暂停；只有明确禁用、锁定或确实没有盘口内容时才标记 `suspended`。
- 优先按比赛ID去重；没有ID时按联赛、主队、客队去重。
- 每个盘口列记录页面标题、识别来源和校验结果；标题与固定结构冲突时停止导出。
- 盘口类型只根据当前列的DOM标题、标签和选项语义识别，不再按第1/2/3列推断。
- 无法同时确认全场/半场和玩法时输出 `unclassified_*`，并将 `market_type_verified` 设为 `false`。
- 让球输出主客方向字段，大小球每个选项输出 `over/under`；比赛计时、补时和开赛时间分开保存。

## 雷速

- `导出滚球分析数据`：执行完整滚球采集，文件名为 `leisu_live_*.json`。
- `导出赛前分析数据`：导出未开赛赛事，文件名为 `leisu_prematch_*.json`。
- 默认最多采集10场，可在页面右下角输入1至100场；只有这批比赛会请求详情接口。
- 可点击“手动选择比赛”，每场左侧会显示复选框；勾选后显示橙色边框，有手动选择时只导出所选比赛。
- 不再提供极速滚球按钮，也不在后台定时自动采集。
- 比分同时输出 `score_source` 和 `score_verified`。
- 详情成功按统计接口和事件接口计算，赔率详情缺失不再误报为整场详情失败。
- 公开输出 `detail_available`、详情组件状态和5/15分钟 `trend`；统计倒退时趋势保持无效。
- 每场增加易读的 `analysis_data`，统一展示实时比分、天气、首发/名单、伤停事件、技术统计、射门、角球、比赛事件、趋势和赔率数据可用性。

## 所有导出

文件包含版本、来源网址、页面标题、采集时间、扫描/有效/过滤或失败数量、导出数量和耗时。导出失败或详情不完整会在页面右下角明确提示。
